# Credits

NUScope is created and led by **Roberto dos Reis** ([@rmsreis](https://github.com/rmsreis)), NUANCE Center,
Northwestern University.

The first NUScope instrument loaders and the PyQt viewer (`NUScopeGUI_v0.py`, `ImageLoadLibraries_v0.py`, kept in
the repository) were written by **Nathaniel Kabat**. The package generalizes those loaders and adds the metadata
schema, provenance, integrity, analysis, saving, Studio and Globus layers.

NUScope builds on [RosettaSciIO](https://hyperspy.org/rosettasciio/), [scikit-image](https://scikit-image.org),
[h5py](https://www.h5py.org), [Zarr](https://zarr.dev), [tifffile](https://github.com/cgohlke/tifffile),
[cryptography](https://cryptography.io) and [globus-sdk](https://globus-sdk-python.readthedocs.io).
